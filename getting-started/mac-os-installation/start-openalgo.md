# Start OpenAlgo

From the `openalgo` directory, start the application with:

```bash
uv run app.py
```

The startup banner reports the endpoints once the server is ready: the web app on `http://127.0.0.1:5000` and the WebSocket proxy on `ws://127.0.0.1:8765`.
